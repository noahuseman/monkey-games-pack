# Monkey Games resource pack

Server branding for the Monkey Games Minecraft PvP practice server.

`monkeygames-pack.zip` adds one bitmap font glyph (`U+E000`, font
`minecraft:monkeygames`) holding the Monkey Games wordmark, so the logo can be
drawn in the scoreboard title and the tab list header, which otherwise render
text only.

Pointed at by `server.properties` via `resource-pack` + `resource-pack-sha1`.
